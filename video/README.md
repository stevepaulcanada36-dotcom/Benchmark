# VideoBench (Benchmark 5): does a multimodal model connect what it sees with what it hears?

A simplified AV-ReasonBench. **We generate every video ourselves**: coloured shapes appear, disappear and flash at
known times, and real sound effects (from ListenBench) play at known times. So every answer is known exactly and
graded by code. There is no LLM judge and no human labelling needed.

| Suite | Scenes | Example questions | Tests |
|---|---|---|---|
| Temporal | 8 x 4 audio conditions | Which shape appears first? When does the blue square appear? Which shape appears at the same moment as the sound? | Event order, timestamps, audio-visual linking |
| Sync | 8 x 4 | Is the sound synchronized with the flashes? What sound is heard? | Detecting delayed audio; telling semantic match from timing |
| Hallucination | 8 x 4 | A dog barks but no dog is shown: "Is a dog visible?" "Is a yellow star visible?" | Audio-driven visual hallucination; inventing sound when there is none |
| Long | 3 x 60 s, 3 x 150 s | First shape? When is the sound heard? Which shape appears right after the sound? | Memory over longer clips |

**Modality ablation**: each short scene comes in 4 versions. `av` is the original. `video_only` has no audio
track. `shifted` has the sound delayed 1.5 s. `swapped` has a different sound at the same times. The correct answer
is defined for each version, so we can measure:
- whether **visual answers stay the same** when the audio is removed or misleading (paired differences);
- whether the model **invents a sound** when there is no audio track;
- whether hearing a dog makes it **"see" a dog**;
- whether it **detects shifted audio**, and names a swapped sound correctly (timing vs meaning, as in AV-SyncBench).

Every answer also carries a timestamp and a confidence, which give two more measures: **"right answer with the
right timestamp"** (grounding) and the **Brier score** (calibration).

**Models**: Gemini via Google AI Studio's **free tier**, which accepts video plus audio natively and costs $0:
`gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, and `gemini-3.8-flash` at 5 frames per second
(an ablation; Gemini samples 1 frame/s by default). Temperature 0, fixed seed, 2 runs.
The models we can reach through AgentRouter cannot take video or audio input, which is why this benchmark uses Gemini.

**Statistics**: 95% CIs come from a cluster bootstrap over scenes: a scene's 4 versions, its questions and its
runs stay together. Models are compared on the same scenes with a paired bootstrap, and the p-values are
Holm-adjusted.

## Run (from the repo root, venv active)

1. Get a free key at https://aistudio.google.com/apikey and add `GEMINI_API_KEY=...` to the repo's `.env`.
2. Build ListenBench first (`cd listen; python -m listenbench build`). VideoBench reuses its 6 sound effects.

```powershell
pip install google-genai imageio-ffmpeg
cd video
python -m videobench build           # renders 102 clips locally (~1 min), free
python -m videobench check-models    # one request per model; remove any that fail from config.yaml
python -m videobench run --pilot     # 16 clips x 4 models, 1 run
python -m videobench report          # look at results/summary.md before the full run
python -m videobench run             # ~700 requests, ~90 min at 8 requests/min; resumes
python -m videobench report
```
If you hit the daily free limit, the run stops cleanly. Run the same command the next day, and finished requests
are kept. `pytest -q` checks the grading and runs everything in fake mode for free.

## Limitations

The scenes are synthetic: simple shapes, no people or real rooms. That gives exact ground truth and rules out
training contamination, but real-world performance will differ. The sounds are generated by ElevenLabs. Only one
model family (Gemini) is tested, because it is the one we can use for free with native video and audio. The free
tier may use prompts to improve Google's products, which is acceptable here because every clip is synthetic.
Stated confidence is the model's own number, so we measure its calibration rather than trust it.
